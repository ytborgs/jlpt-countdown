Widget hiển thị số ngày còn lại đến JLPT N3. Bạn không cần mở web app để xem.

JLPT / N3--NGÀY CÒN LẠI06.12.2026 · 日本語能力試験

Cài đặt một lần trên iPhone

  1. Cài ứng dụng Scriptable từ App Store.
  2. Nhấn Sao chép mã widget bên dưới.
  3. Mở Scriptable → nhấn + → đặt tên JLPT N3 → dán mã → nhấn Done. Chạy một lần để xem bản xem trước.
  4. Giữ ngón tay trên Home Screen → nhấn Sửa/Edit → Thêm Widget → tìm Scriptable → chọn cỡ nhỏ → Thêm Widget.
  5. Giữ ngón tay trên widget mới → Sửa Widget/Edit Widget → mục Script chọn JLPT N3.
Mở Scriptable

Widget xin cập nhật sau nửa đêm giờ Việt Nam. iOS quyết định thời điểm làm mới thực tế nên số ngày có thể cập nhật muộn. Chạm widget sẽ mở trang countdown đầy đủ.
